# Threat Model (`docs/threat-model.md`)

STRIDE threat analysis for `xiaomi-17t-pro-lab` (Build Standard v1.2.0 **B36**), mapped directly to automated verification tests and CI checks.

## 1. System Boundary & Trust Assumptions

- **Client-Side Static Site (GitHub Pages):** Pure ES modules executed in the user's browser sandbox. Zero authentication, zero cookies, zero server-side state, zero external CDN or telemetry requests.
- **Local Development Server (`tools/serve.mjs`):** Loopback-only (`127.0.0.1`) static file server intended for local development and Playwright CI verification, never exposed to untrusted public networks.

## 2. STRIDE Matrix & Verified Mitigations

| Category                   | Concrete Threat                                                                                                          | Mitigation in Code                                                                                                                                                                                                       | Automated Verification Test                                                                                 |
| :------------------------- | :----------------------------------------------------------------------------------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------------------------------------------------------------- |
| **Spoofing**               | Supply-chain tampering of TinyStories-8M weights or vendored assets                                                      | Deterministic 9-shard manifest (`shards.json`) + WebCrypto `SHA-256` verification in `fetchShardedSafetensors` + `data/MANIFEST.sha256` + `CHECKSUMS.sha256` + SLSA attestation (`release.yml`)                          | `tests/rebuild.test.mjs`, `evals/run_tinystories_eval.mjs`, `reference/physics_oracle.py --check-checksums` |
| **Tampering**              | Script/style injection (XSS) via inline DOM styles or `new Function`                                                     | Strict CSP in both `index.html` and `tools/serve.mjs`: `default-src 'self'; script-src 'self' 'sha256-...' ; style-src 'self'; object-src 'none'; form-action 'none'` (zero `unsafe-inline`, zero `eval`/`new Function`) | `tests/v22.test.mjs`, `tests/e2e/smoke.spec.js` (0 console CSP errors across 19 routes)                     |
| **Tampering**              | Directory traversal or prefix-sibling escape (`/repo` → `/repo-secret`) on local dev server                              | `resolveSafe` in `tools/serve.mjs` rejects null bytes, invalid URI encodings, `..`, and absolute `path.relative` escapes; HTTP `403`                                                                                     | `tests/server.test.mjs`                                                                                     |
| **Repudiation**            | Unaudited claims, silent edits, or unverifiable proof scripts                                                            | Linear git history, append-only `docs/run-log.md`, `ERRATA.md`, 6-kernel `lake comparator --paranoid`, `actions/attest-build-provenance@v2`                                                                              | `.github/workflows/ci.yml`, `.github/workflows/release.yml`                                                 |
| **Information Disclosure** | Accidental commit of API keys/tokens or MIME sniffing on served files                                                    | `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer`, report-only `gitleaks` + `osv-scanner` in CI, `Audit-Repo.ps1` secret pattern check                                                                   | `.github/workflows/ci.yml` (`report-only-static`), `tests/properties-and-regressions.test.mjs`              |
| **Denial of Service**      | Uncaught `fs.createReadStream` disk `EIO` crashing server, or `NaN`/huge allocations (`createState(30)`) hanging browser | Stream `error` handler in `tools/serve.mjs` returns clean `500` without crashing; finite/positive domain guards (`1 ≤ nQubits ≤ 12`, `nx, ny ≥ 4`, `parsePort`)                                                          | `tests/properties-and-regressions.test.mjs` (`B06` negative tests & `B21` EIO injection)                    |
| **Elevation of Privilege** | Unauthorized HTTP write methods or cross-origin Spectre timing leakage                                                   | `tools/serve.mjs` enforces `405 Method Not Allowed` outside `GET`/`HEAD`, binds `127.0.0.1` only, and sends `COOP: same-origin` / `COEP: require-corp`                                                                   | `tests/properties-and-regressions.test.mjs` (`B09`)                                                         |
