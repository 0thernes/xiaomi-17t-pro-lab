# Glossary

| Term                     | In this lab                                                                                              |
| ------------------------ | -------------------------------------------------------------------------------------------------------- |
| N3P                      | TSMC 3 nm-class FinFET process used for Dimensity 9500. Not nanosheet GAA.                               |
| N2                       | TSMC’s nanosheet generation. Contrast only.                                                              |
| C1-Ultra / Premium / Pro | The three Arm cores in the official 1+3+4 cluster. Not one core with three clocks.                       |
| SLC                      | 10 MB system-level cache, shared by CPU, GPU, and NPU. Smaller than the 16 MB L3.                        |
| SME2                     | Arm matrix extension on this cluster. The browser lab does not execute it.                               |
| FMA = 2                  | Arm’s GPU op count. A fused multiply-add is two operations.                                              |
| k1                       | Process factor in CD = k1 λ / NA. Physical limit 0.25. Coherent equal lines and spaces cut off near 0.5. |
| Abbe                     | Sum of coherent images, one per source point. The lithography lab’s aerial image.                        |
| MEASURED                 | Taken on this page load.                                                                                 |
| CITED                    | Copied from `specs.json` or a sourced taxonomy facet.                                                    |
| COMPUTED                 | Produced by a formula the page prints.                                                                   |
| UNKNOWN                  | Unpublished in the sources this lab trusts.                                                              |
