# Limitations & Literal-vs-Metaphor Boundary (`LIMITATIONS.md`)

This document states explicitly what `xiaomi-17t-pro-lab` (v3.1.0) **does not prove, measure, or claim** (Build Standard v1.2.0 B41 & Playbook v1.3).

## 1. Hard Scientific & Hardware Boundaries

1. **Zero Open Mega-Atlas Problems Retired (`0 / 1,900`):** This repository does NOT solve any open conjecture or frontier engineering challenge in `0thernes/unsolved-problems-mega-atlas` (see [docs/mega-atlas-cross-reference.md](docs/mega-atlas-cross-reference.md)).
2. **No Browser Execution on MediaTek NPU 990:** Web browsers expose no WebNN/NeuroPilot kernel path to the Dimensity 9500 NPU 990. TinyStories-8M inference (`#/work/llm`) and quantization benchmarks (`#/npu`) run on the visitor's JavaScript CPU thread (or optional WebGL2 shader).
3. **Seven Unpublished Hardware Leaves Remain `UNKNOWN` (`null`):** Nominal battery watt-hours, reverse-wireless wattage, rear glass composition, device UFS lane count (2 vs. 4), official Mali-G1 Ultra MC12 clock frequency, PhoneArena matching iPhone benchmark, and Galaxy street pricing remain explicitly `null` in `data/specs.json`. TSMC N3P fin height, gate length, and high-$k$ dielectric stack thicknesses are proprietary and not claimed.
4. **Formal Proof vs. IEEE-754 Floating-Point Gap:** Pure Lean 4.35.0 (`lean/XiaomiLabProofs/`) certifies exact algebraic, combinatorial, stability, and inequality theorems over `Nat`, `Int`, and `ℤ[i]`. It does NOT formally verify JavaScript/V8 IEEE-754 `Float64` rounding propagation (which is instead checked empirically to `< 2.2e-14` relative error by the independent 60-digit Python oracle `reference/physics_oracle.py`).
5. **Continuum & Paraxial Physical Approximations:**
   - The 2D FDTD thermal solver (`src/sim/thermal-fdtd.js`) models macroscopic mm-scale Fourier diffusion with lumped convective conductance; it does NOT model nanoscale ballistic phonon transport (`CM-039`) or atomic interfacial Kapitza resistance (`CM-064`), and block wattage splits are modeled parameters (`computed`), not leaked silicon telemetry.
   - The 2D EUV lithography engine (`src/sim/litho-2d.js`) uses scalar thin-mask Kirchhoff Fourier optics, not full 3D Maxwell thick-mask absorber FDTD.
6. **Software WebGL on CI Runners:** GitHub-hosted Ubuntu runners execute Playwright via SwiftShader CPU WebGL; physical Mali-G1 Ultra MC12 rendering requires on-device inspection.
7. **Not Externally Peer Reviewed:** The accompanying AMS-LaTeX white paper (`dist/Donahue_2026_Xiaomi_17T_Pro_Lab.pdf`) is an independent research preprint and has not undergone external journal peer review.
