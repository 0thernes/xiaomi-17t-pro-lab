# Runnable Examples (`examples/`)

Self-contained Node.js (`>= 22`) scripts demonstrating direct programmatic use of the verified simulation modules in `src/sim/` (Build Standard v1.2.0 **A43**). All three examples are smoke-tested in CI.

```bash
node examples/01_euv_and_bragg.mjs
node examples/02_thermal_fdtd_iceloop.mjs
node examples/03_quantum_contextuality.mjs
```
